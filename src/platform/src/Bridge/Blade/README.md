Blade Platform
==============

Blade platform bridge for Symfony AI.

Blade (by Shadow) exposes an OpenAI-compatible API served from
`https://api.models.blade.sh`.

Blade Documentation
-------------------

 * [API reference](https://blade.sh/docs/api-reference/)
 * [Models](https://api.models.blade.sh/docs/models.md)
 * [Streaming](https://api.models.blade.sh/docs/streaming.md)
 * [Tool use](https://api.models.blade.sh/docs/tool-use.md)
 * [OpenAI SDK compatibility](https://blade.sh/docs/openai-sdk/)

Supported Models
----------------

Besides chat completions and embeddings, the bridge covers speech to text
(`whisper-large-v3-turbo`), text to speech (`kokoro-82m`) and image generation
(`flux-2-klein`).
